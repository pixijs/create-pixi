Create a PixiJS app with one command

Answer a few prompts and get a working PixiJS 8 project with PixiJS 3D, a dev server, linting and formatting already set up.

Package manager
$npm create pixi.js@latest

Needs Node.js 22.12 or newer.
Then run npm install and npm run dev in the new folder.

Getting started

Pick a template

These commands skip the prompts. Replace my-app with your folder name, or use . for the current folder.

Package manager

Game

A game starter for the platform of your choice, with GSAP, PixiJS UI, PixiJS Sound, PixiJS Filters and Spine.

  • Starter, Web

    Starter, Web language

    A bunny that jumps when you press a button. A standalone browser game built with Vite.

    $npm create pixi.js@latest my-app -- --template starter-web
    Template guide

  • Starter, Web, multiplayer

    Starter, Web, multiplayer language

    A bunny that jumps when you press a button. A standalone browser game built with Vite. Adds a Colyseus server that keeps every player in sync.

    $npm create pixi.js@latest my-app -- --template starter-web-multiplayer
    Template guide

  • Starter, Discord Activity

    Starter, Discord Activity language

    A bunny that jumps when you press a button. Runs inside Discord as an Activity, with Discord sign-in.

    $npm create pixi.js@latest my-app -- --template starter-discord
    Template guide

  • Starter, Discord Activity, multiplayer

    Starter, Discord Activity, multiplayer language

    A bunny that jumps when you press a button. Runs inside Discord as an Activity, with Discord sign-in. Adds a Colyseus server that keeps every player in sync.

    $npm create pixi.js@latest my-app -- --template starter-discord-multiplayer
    Template guide

Bundler

A minimal PixiJS app wired up to the build tool of your choice.

  • Vite

    Vite language

    Instant dev server that reloads on save. The recommended starting point.

    $npm create pixi.js@latest my-app -- --template bundler-vite
    Template guide

  • webpack

    webpack language

    webpack with esbuild-loader for fast TypeScript builds.

    $npm create pixi.js@latest my-app -- --template bundler-webpack
    Template guide

  • esbuild

    esbuild language

    Plain esbuild scripts with a live-reloading dev server and no plugins.

    $npm create pixi.js@latest my-app -- --template bundler-esbuild
    Template guide

  • Import map

    JavaScript only

    No build step. PixiJS loads from a CDN through a browser import map.

    $npm create pixi.js@latest my-app -- --template bundler-import-map
    Template guide

Framework

PixiJS rendered inside a UI framework.

  • React

    React language

    React with @pixi/react, built with Vite.

    $npm create pixi.js@latest my-app -- --template framework-react
    Template guide

Extension

A library project for publishing your own PixiJS plugin.

  • Default

    TypeScript only

    Build, test, document and publish a PixiJS extension with PixiJS Extension Scripts.

    $npm create pixi.js@latest my-app -- --template extension-default
    Template guide

In every project

What every template includes

  • Dev server on port 8080

    Start it with npm run dev. Most templates open it in your browser too.

  • Production build

    npm run build lints your code, type-checks TypeScript, and writes the app to dist/.

  • oxlint and oxfmt

    lint and format scripts, plus VS Code settings that lint and format on save.

  • TypeScript or JavaScript

    Most templates come in both. The JavaScript versions are the same code with the types removed.

The extension template uses PixiJS Extension Scripts for these instead, and the import map template has no build step.
